# 🤖 Mini AI Chatbot

A simple AI chatbot built as a beginner-friendly full-stack project.

## 🚀 Features

- Simple chatbot interface
- Real AI responses
- FastAPI backend
- Groq API integration
- Secure API key using environment variables
- Responsive chat interface

- JavaScript
- Python
- FastAPI
- Groq API
